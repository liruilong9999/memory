# memory

人格记忆系统（Persona Memory System）：让 agent 拥有"连续人生"。

不是更大的记忆库，而是一套有动力学的记忆机制：**分层记忆图谱 + 突触 + 触发阈值 + 状态机 + 时间感**。目标是人格连续性（同一个主体在成长），不是任务成功率。
