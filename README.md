# memory

稳定记忆系统（Stable Memory System）：让 agent 记得住、记得对、忘得合理、找得回。

阶段目标收敛为**稳定记忆**——数据不丢、内容一致、行为可解释、成本有上界。人格连续性、双人格、分身等属于后续方向，本阶段不做。
