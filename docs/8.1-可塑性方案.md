# 记忆图谱可塑性边权机制：数学问题分析与改造方案

## 一、问题结论

当前记忆图谱采用「加性强化 + 乘性衰减 + 离散量化」的边权更新机制，希望通过边权反映两条记忆之间的共同激活频率。

经过分析，当前机制存在以下问题：

1. **多固定点问题**：相同的使用频率，可能因为初始权重不同而收敛到不同的最终权重。
2. **强化抵消问题**：强化步长与线性衰减地板相等，导致大量状态下单次强化完全无效。
3. **频率不可分辨问题**：最终边权不能可靠地反映实际共同激活次数。
4. **参数耦合问题**：量化精度、强化步长和衰减地板被绑定，调整一个参数会影响其他机制。
5. **语义混淆问题**：原边权同时承担语义相似度和使用频率两个职责。

**最终建议：采用指数移动平均（EMA，指数移动平均）估计边的使用强度，将语义相似度和动态使用频率分离。**

推荐更新公式：

[
\boxed{
w_{t+1}=fw_t+(1-f)\cdot\min\left(\frac{n_t}{10},1\right)
}
]

其中：

- (w_t)：当前使用频率权重。
- (n_t)：当晚共同激活次数。
- (f)：历史权重保留系数，建议 0.98。
- (1-f)：新使用记录的学习系数，建议 0.02。

该模型可以实现 10 个不同使用档位、唯一稳定值、无初始状态依赖以及自然遗忘。

## 二、原模型分析

### 2.1 原始数学机制

边权范围：

[
w\in[0,1]
]

量化函数：

[
Q(x)=\frac{\operatorname{round}(100x)}{100}
]

状态集合：

[
W={0.00,0.01,\ldots,1.00}
]

强化算子：

[
R(w)=Q(\min(1,w+\delta))
]

衰减算子：

[
D(w)=
\begin{cases}
Q(fw), & Q(fw)<w\
Q(\max(0,w-0.01)), & \text{其他情况}
\end{cases}
]

每晚执行：

[
w_{t+1}=D(R^n(w_t))
]

其中 (n) 为当晚共同激活次数。

### 2.2 原模型存在多固定点

以参数：

[
\delta=0.01,\quad f=0.98
]

为例，使用不同初始值进行迭代，会进入不同的固定点。

根据已有实测：

| 每晚使用次数 | 固定点范围或结果 |
| ------------ | ---------------- |
| 1            | 0.00～0.74       |
| 2            | 0.74～0.98       |
| 3            | 0.98             |
| 4            | 0.98             |
| 5            | 0.98             |

其中，使用一次时，从 0.50 开始最终仍为 0.50；使用两次时最终为 0.74；使用三次时最终为 0.98。

这意味着原模型的最终权重取决于初始状态及历史路径，而不只是使用频率。

因此，不能将原模型的最终权重简单定义为使用次数的函数。

### 2.3 修正原模型的单调性判断

原题面认为量化导致映射非单调，这个判断不准确。

将权重转换为整数状态：

[
k=100w
]

令：

[
q_f(j)=\operatorname{round}(fj)
]

则衰减算子可以表示为：

[
D(j)=\max(0,\min(q_f(j),j-1))
]

其中 (j) 为衰减前的整数权重状态。

由于 (q_f(j)) 和 (j-1) 都是单调不减函数，它们的最小值仍然单调不减。

强化算子也单调不减，因此整体转移函数仍然单调不减。

对于有限状态空间，单调不减的确定性映射不会产生长度大于 1 的周期轨道。

所以，原模型的主要问题是：

**存在大量固定点，不同初始状态进入不同的固定点，而不是产生复杂周期振荡。**

### 2.4 原推导中的代数错误

在不考虑量化、线性地板和权重上限的连续模型下：

[
w^*=\frac{nf\delta}{1-f}
]

相邻使用档位的稳态差：

[
\Delta w^*=\frac{f\delta}{1-f}
]

要让相邻档位相差大于 0.01：

[
\frac{f\delta}{1-f}>0.01
]

正确整理：

[
\boxed{\delta>\frac{0.01(1-f)}{f}}
]

原推导错误地写成：

[
\delta>\frac{0.01}{f}
]

遗漏了因子 (1-f)。

考虑不撞顶条件：

[
N\frac{f\delta}{1-f}<1
]

得到：

[
\delta<\frac{1-f}{Nf}
]

若进一步要求 (\delta\geq0.01)，则连续模型中的必要条件为：

[
\boxed{N<\frac{1-f}{0.01f}}
]

但该公式只适用于未量化、无衰减地板、未饱和的连续模型，不能直接当作实际 101 状态系统的严格档数上界。

### 2.5 线性地板导致强化抵消

原模型在比例衰减不足一个量化格时，强制下降 0.01。

默认参数：

[
\delta=0.01,\quad f=0.98
]

当当前权重为 0.10：

[
0.10\xrightarrow{强化}0.11
]

[
Q(0.11\times0.98)=Q(0.1078)=0.11
]

触发线性地板：

[
0.11-0.01=0.10
]

最终回到原值。

已有实测结果：

| 单步变化 | 格点数 |
| -------- | ------ |
| 不变     | 75     |
| 上升     | 0      |
| 下降     | 26     |

这意味着，在大量低权重区域，每晚共同激活一次无法产生任何正向增长。

线性地板不是唯一的多固定点来源。即使删除地板，逐次量化本身仍可能制造固定点。

因此，应该同时取消逐次量化和强制最小衰减。

## 三、Q1～Q6 的分析结论

### Q1：多固定点是否意味着需求提错？

需求没有错，原模型的数学表达方式不合适。

原模型试图通过强化累积值表达长期共同激活频率，但没有直接估计使用频率。

建议改为：

[
w_{t+1}=(1-\alpha)w_t+\alpha u_t
]

其中：

[
\alpha=1-f
]

输入 (u_t) 不应只采用 0 或 1，否则无法区分每晚使用一次和十次。

建议：

[
u_t=\min(n_t/10,1)
]

这样权重直接表示最近一段时间内的指数加权使用强度。

### Q2：原档数上界是否正确？

原推导存在代数错误。

连续模型中的相邻稳态间距公式本身成立，但原下界整理错误。

此外，连续公式不能直接用于带量化和线性地板的实际代码。

实际离散系统应基于状态转移函数分析固定点与吸引域。

### Q3：线性地板破坏了什么？

线性地板把比例衰减与固定步长衰减混合在一起。

它会制造强化与衰减的精确抵消，但量化舍入本身也会造成固定点。

不建议改用对数尺度衰减，也不建议继续使用人为设置的最小衰减量。

建议直接删除线性地板，使用统一的比例遗忘机制。

### Q4：饱和式强化是否可行？

连续饱和式强化：

[
R(w)=w+\beta(1-w)
]

连续执行 (n) 次：

[
R^n(w)=1-(1-w)(1-\beta)^n
]

再执行乘性衰减：

[
w_{t+1}=fR^n(w_t)
]

唯一固定点：

[
\boxed{
w_n^*=
\frac{f[1-(1-\beta)^n]}
{1-f(1-\beta)^n}
}
]

对于 (0<f<1)、(0<\beta<1)，稳态随 (n) 严格递增。

因此，连续模型并不存在最多五档的理论限制。

但逐次量化后仍需要重新进行状态机验证。

该方案可以作为备选，不建议优先采用，因为它不如使用率估计模型直观。

### Q5：提高量化精度是否足够？

不够。

仅仅提高精度，如果强化步长和衰减地板仍然绑定，抵消问题可能原样重现。

即使两者同时缩小，也只是将抵消转移到更细的格点上。

应该取消逐次量化，并将内部计算与展示精度分离。

### Q6：三个参数是否应该解耦？

应该。

原来三个概念被绑定：

| 参数     | 应有职责               |
| -------- | ---------------------- |
| 量化精度 | 数值存储和展示精度     |
| 强化步长 | 旧模型中的强化幅度     |
| 衰减地板 | 旧模型中的最小衰减幅度 |

推荐的新模型不再需要独立强化步长和衰减地板。

遗忘和学习由 (f) 与 (1-f) 统一控制。

## 四、推荐模型：使用频率的指数移动平均

### 4.1 数学公式

最终推荐：

[
\boxed{
w_{t+1}=fw_t+(1-f)u_t
}
]

使用强度：

[
\boxed{
u_t=\min\left(\frac{n_t}{10},1\right)
}
]

建议：

[
f=0.98
]

因此：

[
\boxed{
w_{t+1}=0.98w_t+0.02\min(n_t/10,1)
}
]

该机制的核心是：将当前权重与当晚的使用强度进行加权平均。

不再分别执行强化和衰减。

### 4.2 十个使用档位

当每天使用次数固定为 (n)：

[
w^*=fw^*+(1-f)\frac{n}{10}
]

求解：

[
\boxed{w^*=\frac{n}{10}}
]

稳态结果：

| 每晚共同激活次数 | 最终权重 |
| ---------------- | -------- |
| 1                | 0.1      |
| 2                | 0.2      |
| 3                | 0.3      |
| 4                | 0.4      |
| 5                | 0.5      |
| 6                | 0.6      |
| 7                | 0.7      |
| 8                | 0.8      |
| 9                | 0.9      |
| 10               | 1.0      |

十个档位全部不同。

当每晚使用次数固定时，不同初始权重最终都会收敛到相同结果。

### 4.3 遗忘速度

半衰期公式：

[
T_{1/2}=\frac{\ln(0.5)}{\ln(f)}
]

当 (f=0.98)：

[
\boxed{T_{1/2}\approx34.31\text{ 夜}}
]

符合原有的长期记忆需求。

### 4.4 唯一稳定值的证明

对于固定的输入 (u)：

[
F(w)=fw+(1-f)u
]

求固定点：

[
w^*=fw^*+(1-f)u
]

得到：

[
w^*=u
]

任意初始值经过 (t) 夜迭代：

[
w_t=u+f^t(w_0-u)
]

当：

[
0\leq f<1
]

有：

[
\lim_{t\to\infty}f^t=0
]

因此：

[
\boxed{\lim_{t\to\infty}w_t=u}
]

这证明固定输入下存在唯一稳态，并且与初始权重无关。

另外，由于更新是两个 [0,1] 区间内数值的凸组合，权重始终处于 [0,1]。

### 4.5 使用频率的语义说明

当前推荐的输入：

[
u_t=\min(n_t/10,1)
]

表示当晚的归一化共同激活强度。

因此，长期稳定使用一次对应 0.1，长期稳定使用十次对应 1.0。

如果产品真正想表达的是「一夜内是否使用过」，而不是使用次数，则应改为：

[
u_t=
\begin{cases}
1,&n_t>0\
0,&n_t=0
\end{cases}
]

这两种语义不能混淆。

当前方案选择按共同激活次数估计使用强度，以满足区分 1～10 次的需求。

## 五、工程架构调整

### 5.1 分离语义相似度和使用频率

原边权不应该继续同时表达两个概念。

建议修改边的数据结构：

```
interface MemoryEdge {
    // 静态语义相似度
    semanticWeight: number;

    // 动态使用频率
    usageRate: number;

    // 最近一次更新日期
    lastUpdatedAt: number;
}
```

字段职责：

| 字段           | 含义                           | 更新方式             |
| -------------- | ------------------------------ | -------------------- |
| semanticWeight | 两条记忆本身的语义相关程度     | 创建或重新评估时更新 |
| usageRate      | 两条记忆实际共同激活的频率强度 | 每晚根据使用次数更新 |
| lastUpdatedAt  | 最近一次频率更新的时间         | 更新时维护           |

新建边时：

- `semanticWeight` 使用原有相似度计算结果。
- `usageRate` 初始化为 0。
- 不再将语义相似度直接当作使用频率。

### 5.2 权重更新代码

建议采用如下实现：

```
const DECAY_FACTOR = 0.98;
const MAX_DAILY_USAGE = 10;

function updateUsageRate(
    currentWeight: number,
    nightlyCount: number
): number {
    const current = Number.isFinite(currentWeight)
        ? Math.min(1, Math.max(0, currentWeight))
        : 0;

    const count = Number.isFinite(nightlyCount)
        ? Math.max(0, Math.floor(nightlyCount))
        : 0;

    const usage = Math.min(
        count / MAX_DAILY_USAGE,
        1
    );

    return (
        DECAY_FACTOR * current +
        (1 - DECAY_FACTOR) * usage
    );
}
```

实现要求：

1. 使用双精度浮点数进行内部计算。
2. 每次更新后不再调用量化函数。
3. 不再设置固定步长衰减地板。
4. 使用次数超过 10 时，按 10 次处理。
5. 使用次数为 0 时，正常执行自然遗忘。
6. 非法数值和负数应进行边界处理。

### 5.3 检索评分

检索时可以将语义相关性与实际使用频率组合：

[
Score=\lambda S_{semantic}+(1-\lambda)S_{usage}
]

其中：

- (S_{semantic})：语义相似度。
- (S_{usage})：使用频率权重。
- (\lambda)：语义权重占比。

(\lambda) 暂时不指定固定值，应通过真实检索效果测试确定。

这样可以避免一条记忆因为暂时没有被使用，就丢失其本身的语义关联。

## 六、数据迁移方案

建议采用兼容式迁移，不直接覆盖原有边权。

| 旧数据             | 新数据         | 处理方式                 |
| ------------------ | -------------- | ------------------------ |
| 原边权             | semanticWeight | 原值保留                 |
| 无历史使用记录     | usageRate      | 初始化为 0               |
| 有原始共同激活日志 | usageRate      | 可以通过历史事件重新计算 |
| 原关联关系         | 新关联关系     | 完全保留                 |
| 原边权变化日志     | 历史日志       | 保留，不重新解释         |

特别注意：

旧边权已经存在历史路径依赖，不能根据旧权重反推出真实的使用频率。

没有原始共同激活记录时，不应将旧边权直接转换为 usageRate。

### 存储精度

建议：

- 内部使用双精度浮点数。
- 数据库存储应保证足够的小数精度。
- 展示时可以保留 2～3 位小数。
- 不应在每次更新时舍入到 0.01。
- 比较浮点数时采用误差容限。

### 惰性衰减

为避免每天遍历和更新全部边，可以采用惰性衰减。

如果某条边距离上次更新已经过去 (\Delta t) 夜，且期间没有共同激活：

[
\boxed{
w_{now}=f^{\Delta t}w_{last}
}
]

在有新使用事件时，再将衰减结果与当晚使用强度进行一次 EMA 更新。

这样可以减少无意义的数据库写入和日志体积。

注意：批量历史事件的处理必须保留每日事件顺序，不能将多天的事件简单合并成一次更新。

## 七、验收测试

不应仅凭参数扫描判断模型是否正确，应建立确定性的单元测试。

| 编号 | 测试内容     | 输入              | 预期结果               |
| ---- | ------------ | ----------------- | ---------------------- |
| T1   | 每晚使用一次 | n=1               | 收敛至 0.1             |
| T2   | 每晚使用两次 | n=2               | 收敛至 0.2             |
| T3   | 每晚使用十次 | n=10              | 收敛至 1.0             |
| T4   | 不同初始权重 | 0、0.5、1         | 收敛到相同目标         |
| T5   | 长期不使用   | n=0               | 按 34.31 夜半衰期衰减  |
| T6   | 初始权重为零 | n=1               | 第一次更新后权重大于零 |
| T7   | 使用次数递增 | n=1～10           | 稳态严格递增           |
| T8   | 边界条件     | 任意合法输入      | 权重始终在 [0,1]       |
| T9   | 非法输入     | 负数、NaN、无穷值 | 正确进行边界处理       |
| T10  | 惰性衰减     | 多夜没有使用      | 与逐夜执行结果一致     |

建议以 600 夜作为主要收敛测试周期。

当 (f=0.98) 时：

[
0.98^{600}\approx5.5\times10^{-6}
]

初始状态的影响已经非常小。

测试浮点数时使用误差容限，不使用严格相等判断。

## 八、最终改造决策

| 项目           | 原方案               | 新方案                     |
| -------------- | -------------------- | -------------------------- |
| 权重语义       | 混合相似度和使用历史 | 分离语义相似度与使用频率   |
| 强化机制       | 固定步长加性强化     | 使用次数归一化             |
| 衰减机制       | 比例衰减 + 线性地板  | 指数遗忘                   |
| 量化机制       | 每次更新后量化       | 内部不量化                 |
| 多固定点       | 存在                 | 固定输入时唯一稳态         |
| 初始状态影响   | 可能长期保留         | 随时间指数消失             |
| 使用次数分辨率 | 不稳定               | 1～10 次对应 10 个稳态     |
| 遗忘半衰期     | 受多个机制共同影响   | 由 f 独立控制              |
| 数据迁移       | 原权重存在语义混淆   | 保留语义权重，新增频率字段 |

### 最终推荐参数

| 参数               | 推荐值      |
| ------------------ | ----------- |
| 历史保留系数 f     | 0.98        |
| 学习系数 1-f       | 0.02        |
| 最大归一化使用次数 | 10          |
| 半衰期             | 34.31 夜    |
| 内部计算           | 双精度浮点  |
| 展示精度           | 2～3 位小数 |

最终更新公式：

[
\boxed{
w_{t+1}=0.98w_t+0.02\min(n_t/10,1)
}
]

## 九、结论

当前问题不是简单调整 (\delta)、(f) 或量化精度就能从根本上解决的。

原模型把累计强化分数当作使用频率，导致量化、强化和衰减之间产生结构性冲突。

应该改变设计思路：

1. 原始语义相似度作为静态关联信息保存。
2. 使用频率通过 EMA 独立估计。
3. 遗忘由统一的比例系数控制。
4. 内部计算不进行逐次量化。
5. 检索阶段组合语义相关性和使用频率。

**最终目标不是让边权不断累积强化，而是让边权成为两条记忆实际共同激活强度的在线估计。**

这样既保留了长期记忆的遗忘机制，也解决了原模型的多固定点、强化抵消和频率不可分辨问题。
