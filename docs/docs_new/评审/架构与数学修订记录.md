# 架构与数学修订记录

## 一、范围与证据口径

本轮只修订本系列主篇 00～12 及本记录。任务是让架构契约和数学推导可用于决策，
不据文档改动推定实现已经具备能力。各组作者交换审查，修复意见由另一组复核；
作者的公式自检只验证推导，不作为独立审查。

新增实质方案统一按「设计决策·待验证」理解。既有材料里的实测数字保留为历史观测，
本轮没有重跑系统探针，也没有把未复现的数字变成新方案的效果证据。

## 二、影响域与变更预算

允许修改：架构承诺、数学公式与算例、边界条件、对应流程图、术语和验收口径。
禁止扩展：实现代码、工程配置、依赖、宿主行为、无关产品功能与未经测量的性能结论。
跨篇同步只沿共同契约展开，不改变本系列面向外部架构评审者的用途。

以下属于承重契约，改动时必须同时复核相关篇目：

| 高风险契约 | 涉及篇目 | 本轮推荐基线 | 必须守住的边界 |
|---|---|---|---|
| 操作身份与实体修订 | 03、04、05、07、11、12 | 稳定操作身份、负载指纹、预期修订各自独立 | 同一操作重试不重复；甲改乙再改甲不能被内容去重吞掉 |
| 持久提交与一致发布 | 02～05、07、11、12 | 明确提交单元、故障模型、回执与进度；发布兼容读取版本 | 单行追加不等于持久原子性；水位比对不等于写者互斥 |
| 当前来源与派生依赖 | 04、05、07、11、12 | 当前修订保留精确来源集合，历史另行留痕 | 来源修正、删除、撤权后，旧摘要和旧关系不能继续当有效证据 |
| 删除与恢复 | 01、03、04、05、07、11、12 | 先使目标与派生闭包不可见，再净化受管副本；恢复校验最新屏障 | 逻辑删除不等于物理擦除；旧备份自身不能证明后来没有删除 |
| 一次召回的输入 | 01、03、06、08、09、11、12 | 固定提交水位、配置、图谱代次、时刻与权限；发送许可前复核撤销 | 图谱端点存活不证明修正后的关系仍成立 |
| 相关资格与排序 | 00、01、06、08～12 | 相关分量决定资格，总分表达偏好；相对基准在扩散前冻结 | 不能让无关高分卡或扩散加分抬高共同筛选基准 |
| 词元预算 | 00、01、02、06、09、11、12 | 计量完整渲染文本，并绑定目标模型的分词规则 | 字符估算不是通用硬上界；模板与元数据不能漏计 |
| 图谱与扩散预算 | 00、01、07～12 | 区分主动提名与实际度；每种子到目标取最强路径，归一后限制全轮加分 | 对称近邻并集不封顶单点度；重复关系和多路径不能自动变成独立证据 |
| 遗忘结算 | 04、07、09、10、12 | 独立强度结算时刻，参数变化前结算旧区间，公平轮转续跑 | 普通更新时间不代表已经衰减；单批上限不保证长期不积压 |
| 重复合并 | 07、09、11、12 | 连通分量只作候选，实际组全对达标，预算耗尽延后 | 集合相似度不传递；合并身份稳定不证明访问计数可反复相加 |
| 时间摘要 | 00、04、05、07、09、11、12 | 日分区账本始终保留来源，分别汇入周、月；展示门槛独立 | 跨月自然周不重复归属；低量日不能因无摘要文本而消失 |
| 可塑性与容量 | 00、01、07、09、10、12 | 将既有粗量化模型的失败限定在其前提内，列出高精度候选与容量前提 | 不能把一个递推失败写成全部方法无解，也不能由归档推导总库有界 |

## 三、数学检查与反例

这些检查是可复算的数学证据，不是系统效果测量。

| 检查 | 结论 | 对应篇目 |
|---|---|---|
| 甲改乙再改甲 | 内容历史键会把第三个合法操作误当重复；三个操作身份可区分 | 04、05 |
| 集合相似度的传递反例 | 相邻两对为 10/11，首尾为 9/11；阈值 0.86 下不能整组件合并 | 07、09 |
| 近邻的星形构造 | 每点提名一个邻居，中心仍可有任意多个入边 | 08、09 |
| 评分可达区间 | 算例必须同时满足相关分量、查询无关权重和冲突扣分的共同限制 | 06、09 |
| 扩散的零输入、重数与预算 | 零能量无加分；重复边不额外计证；全轮加分受同一预算限制 | 08、09、10、12 |
| 指数移动平均的周期输入 | 周期稳态会波动，均值、峰值与量化后不动点不能混为一谈 | 00、09、10 |
| 衰减的分段结算 | 固定半衰期可按经过时间组合；半衰期变化必须分段积分 | 07、09 |
| 百次零错误样本 | 在独立同分布假设下，单侧 95% 错误率上界约 2.95%，不是总体零错误 | 12 |
| 活跃规模估计 | 只在流入、半衰期、处理延迟与增强等前提明确时可推导条件上界 | 07、12 |

## 四、如何验收这些方案

先验数学不变量和故障协议，再回放跨模块场景，最后用独立标注和真实宿主验证业务闭环。
静态格式检查只证明文档结构可读取，不能替代公式复核、崩溃注入或用户效果评估。

质量评估冻结语料、参数与版本，以相同输入做配对比较，分别统计相关性、误引用、删除残留、
延迟和资源消耗；影子排名变化只说明机制有作用，不证明它对用户有益。

## 五、诚实边界

本轮不提供实现符合性证明、性能新测量、断电恢复结果或真实用户收益结论。
推荐方案是在现有目标下更保守、可解释且可验收的设计基线，尚未证明全局最优；
是否胜过既有方案，仍需按第 12 篇执行独立对照与故障验收。
